# 디스토피아 카탈로그 (관리자 화면 버전)

- 카탈로그: `주소/` (비밀번호 필요, 처음 비밀번호는 `disfur` 그대로)
- 관리자 화면: `주소/admin` (PIN 필요)

## 설정 순서 (지금 쓰는 catalog 저장소를 그대로 써요. 주소도 그대로예요)

### 1. GitHub 파일 바꾸기
1. 지금 저장소에서 **예전 파일을 지워요**: `index.html`, `catalog.html`, `auth.html`, `images` 폴더 안 파일 8개.
   - 파일을 열고 오른쪽 위 ⋯ → **Delete file** → Commit.
2. 이 zip을 풀어서 나온 파일·폴더를 전부 올려요. (`api`, `lib`, `data`, `templates`, `public`, `vercel.json`, `package.json`, `README.md`)
   - `api/index.js`, `api/auth.js`, `vercel.json`은 같은 이름이라 덮어쓰기 돼요.
   - 폰에서 폴더째 올리기가 안 되면, 폴더마다 들어가서 **Add file → Upload files**로 올려요. (예: `lib` 폴더 안에 `store.js`, `http.js`)

### 2. 저장소(Upstash Redis) 연결
- Vercel → catalog 프로젝트 → **Storage** 탭.
- **노노라무·행사 캘린더 때 만든 Redis를 같이 써도 돼요.** 기존 저장소를 골라 **Connect Project**로 이 프로젝트를 연결해요. 이 사이트 데이터는 이름 앞에 `dcat:`이 붙어서 섞이지 않아요.

### 3. 환경변수
Settings → Environment Variables

| 이름 | 값 |
|---|---|
| `OWNER_PIN` | 처음 쓸 관리자 PIN (숫자 6자리 이상 추천) |

넣은 뒤 **Deployments → 맨 위 ⋯ → Redeploy**.

### 4. 확인
1. `주소/admin` → PIN 입력 → 기존 상품 84개가 그대로 보이면 성공이에요. (처음 열 때 기존 상품·파트너가 자동으로 들어가요)
2. **설정** 탭 → 행사 캘린더 주소를 넣고 저장 → 카탈로그 탭 줄에 📅 행사 일정 버튼이 생겨요.
3. 폰 크롬 메뉴 → **홈 화면에 추가**로 관리 화면을 앱처럼 쓸 수 있어요.

## 쓰는 법
- **새 상품**: 오른쪽 아래 ＋ 버튼. 새 상품은 목록 맨 위에 들어가요.
- **사진**: 📷 폰 사진을 고르면 자동으로 줄여서 올려요. 🔗 트위터 사진 주소를 붙여넣어도 돼요. 첫 번째 사진이 대표 사진이에요.
- **숨기기**: 품절이나 준비 중일 때 지우지 말고 숨기기를 켜요.
- **순서**: 목록의 ▲▼로 바꿔요. 카탈로그에도 그 순서로 보여요.
- **복제해서 새로 만들기**: 비슷한 상품은 복제한 뒤 이름·가격만 바꿔요.
- **필터 목록**: 설정 탭에서 용도·재질 버튼을 추가하거나 순서를 바꿔요.
- **카탈로그 비밀번호**: 설정 탭에서 바꿔요. 바꾸면 손님도 새 비밀번호를 다시 넣어야 해요.
- PIN을 10번 틀리면 10분 동안 막혀요.
